Public Widget Test

Bubble + iframe widget load từ dist-widget/chatbot-widget.iife.js (sau khi chạy npm run build:widget để đồng bộ bundle mới). API key là UUID trả về field apiKey duy nhất lúc POST /api/chatbots (không hiện lại trong list).

Mở kèm query để không sửa file: ?widgetKey=<apiKey-uuid> hoặc ?apiKey=<uuid>

Ví dụ: http://localhost:5173/public-widget-test.html?widgetKey=YOUR_UUID
